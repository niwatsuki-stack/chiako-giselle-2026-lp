バレエ用語解説
— 観劇前の 25 用語 —

「パ・ド・ドゥ」「ヴァリエーション」「コール・ド」 — 観劇前に押さえておくと作品の見え方が 100 倍変わる バレエの基本用語を、 25 個に厳選して解説します。

該当する用語が見つかりませんでした。

— DANCERS / ダンサー —

プリンシパルPrincipal
バレエ団の最高位のダンサー。 主役を務める。 ジゼルでは ジゼル・アルブレヒト・ミルタ が主要プリンシパル役。
ソリストSoloist
プリンシパル に次ぐ位。 単独で踊る ヴァリエーション を任される。
コール・ド・バレエCorps de Ballet
群舞を担当するダンサーたち。 「コール・ド」 と略す。 ジゼル第2幕の ウィリの群舞 はバレエ史上最も有名なコール・ドのひとつ。
エトワールÉtoile
フランス語で「星」。 パリ・オペラ座バレエの最高位を指す。 国によって名称が異なる(英ロイヤルでは「プリンシパル」)。

— STRUCTURE / 構成 —

パ・ド・ドゥPas de Deux
フランス語で「2人の踊り」。 男女ペアで踊る バレエの最も華やかな見せ場。 通常 アダージョ → 男性 ヴァリエーション → 女性 ヴァリエーション → コーダ の 4部構成。
ヴァリエーションVariation
独舞。 1人のダンサーがソロで技術を披露する場面。 短いが ダンサーの個性とテクニックが最も際立つ。
アダージョAdagio
パ・ド・ドゥの冒頭部分。 ゆっくりとした音楽で 男性が女性をリフトしたりサポートして踊る。 ジゼルとアルブレヒトの第2幕アダージョが有名。
コーダCoda
パ・ド・ドゥの終結部。 男女が交互に技を披露し、 ピルエット連続技などで盛り上がって幕を閉じる。
グラン・パGrand Pas
大規模な踊り。 複数のソリストとコール・ドが入り乱れる、 バレエの中の クライマックス場面。

— MOVES / 技法 —

アラベスクArabesque
片足で立ち、 もう一方の足を後方に伸ばしたポーズ。 バレエの最も美しい姿勢のひとつ。 ジゼル第2幕で何度も登場する。
アチチュードAttitude
アラベスクの足を膝で曲げたバージョン。 より優雅で柔らかい印象。
ピルエットPirouette
片足での回転。 1回転 / 2回転 / 3回転と回数で技術が分かる。 連続ピルエットは観客が拍手で応えるポイント。
グラン・ジュテGrand Jeté
大きく前へ跳ぶジャンプ。 空中で両足を 180 度開く。 男性プリンシパルの代名詞。
フェッテFouetté
片足を軸に、 もう一方の足で空中を蹴って連続回転。 「白鳥の湖」 の黒鳥が連続 32回転することで有名。
アン・ポワントEn Pointe
つま先立ち。 トゥシューズを履き、 つま先のみで立つ女性の象徴的な技法。 ロマンティック・バレエで多用される。

— COSTUME / 衣装 —

トゥシューズPointe Shoes
つま先立ちのための専用シューズ。 1 足を本番で履き潰すこともある消耗品。 1万円超のものが多い。
チュチュTutu
バレエ衣装の代表。 2 種類あり: クラシック・チュチュ(短くて水平に広がる、 白鳥の湖型)と ロマンティック・チュチュ(長くて柔らかい、 ジゼル・ウィリ型)。
レオタードLeotard
ダンサーが普段の稽古で着る、 体にフィットした衣装。 公演ではこの上にチュチュやドレスを重ねる。

— STAGE / 舞台 —

プロムナードPromenade
女性がアラベスクなどの姿勢で立ち、 男性がその周りを支えながらゆっくり一周させる動き。
マイムMime
セリフを使わず身振りで物語を伝える表現。 「愛している」「死んでしまった」「結婚しよう」 など定型表現がある。 ジゼル第1幕のマッド・シーンも一種のマイム。
カーテンコールCurtain Call
公演終了後、 ダンサーが舞台に再登場して観客の拍手に応える時間。 主役のソロカーテンコール → 全員のカーテンコールの順で進む。
ブラボー / ブラーバBravo / Brava
素晴らしいダンサーへの賞賛の声。 男性に「ブラボー」、 女性に「ブラーバ」、 複数人に「ブラビー」 と言い分ける(知っていると上級者気分)。

— GENRE / ジャンル —

ロマンティック・バレエBallet romantique
19 世紀前半に成立した、 幻想的・超自然的なテーマ を扱うバレエ。 ジゼル / ラ・シルフィード が代表作。 妖精・精霊・夢の世界が好まれる。
クラシック・バレエBallet classique
19 世紀後半 〜 20 世紀初頭に成立。 白鳥の湖 / 眠れる森の美女 / くるみ割り人形 などペティパ&チャイコフスキー作品が代表。 構造が確立。
ウィリWilis
ジゼル第2幕に登場する精霊。 結婚を前に裏切られて死んだ娘たちの霊で、 森に迷い込んだ男を踊らせて死に至らしめる。
